# SocialSyn

A digital marketing agency website built with Next.js and Express.js.

## Project Structure

- **Frontend/**: Next.js 15 application
- **Backend/**: Express.js API server

## Getting Started

### Frontend
```bash
cd Frontend
npm install
npm run dev
```

### Backend
```bash
cd Backend
npm install
npm run dev
```

## Environment Setup

Copy `.env.example` to `.env` in each directory and configure your variables.

## Built With

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Express.js
- MongoDB# Trigger deployment
